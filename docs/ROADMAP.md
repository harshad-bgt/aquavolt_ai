# Roadmap

## CURRENT
- **Backend + Database + Frontend Core**: React application shell, real JWT authentication, SQLite database integration, dashboard functionality, Farm Monitoring, Farm Analytics, and AI Advice Module (Rule-based decision engine).

## NEXT
- **Borewell & Soil Modules**: Deep-dive analytics for specific farm domains.

## FUTURE
- **AI Engine & Integrations**: Sensor integration, Weather integration, Solar Forecasting, Borewell Modeling, Recommendation Engine, Analytics, IoT, Pump Control.
- **PostgreSQL Migration**: Move from SQLite to PostgreSQL for production readiness.
