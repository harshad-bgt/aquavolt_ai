# Project Overview

## What AquaVolt AI is
AquaVolt AI is a real-world agricultural technology platform designed to help farmers manage water and energy more intelligently.

## Who it is designed for
Farmers who want to optimize their irrigation and pump-operation decisions based on water, energy, borewell, crop, weather, and solar conditions.

## The problem it addresses
Provides a decision-support system to inform farmers when to irrigate, how long to run pumps, what the expected water/energy requirements are, and how the borewell is behaving.

## Long-term product vision
"An AI-Powered Water + Energy Management System for Agriculture." A full ecosystem combining sensor data, AI predictions, and IoT controls.

## Current development scope
- Frontend UI using React and Vite
- Responsive application shell (Sidebar, navigation, etc.)
- Mock authentication (Login, Sign Up, Forgot Password)
- Farm onboarding UI
- Language selector (UI currently in English)
- Dashboard UI with realistic development data
- Reusable design system

## Future development scope
- Backend (FastAPI, PostgreSQL)
- Production database & Authentication server
- Real API integrations (weather, sensors, IoT, pump controllers)
- AI Engine, Machine Learning, predictive analytics
- Real-time sensor streaming

## Technology stack
- Frontend: React, Vite, TypeScript, Tailwind CSS, React Router, Lucide React, Recharts.

## Important design principles
- Must look like a real agricultural technology product (professional, natural, calm, trustworthy).
- Interface should prioritize usability over visual effects.
- Avoid generic SaaS/AI-generated looks, neon colors, glassmorphism, etc.
