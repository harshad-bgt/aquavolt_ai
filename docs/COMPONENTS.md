# Components

*This document will be updated as components are implemented.*

## Implemented UI Components
- **Button** (`src/components/ui/Button.tsx`): Supports variants (primary, secondary, outline, ghost), sizes, and loading state.
- **FormInput** (`src/components/ui/FormInput.tsx`): Reusable input component with standard styling, labels, helper text, and error states.
- **PasswordInput** (`src/components/ui/PasswordInput.tsx`): Extension of FormInput that includes a visibility toggle (eye icon).
- **Card** (`src/components/ui/Card.tsx`): Reusable surface container with different padding options.
- **Badge** (`src/components/ui/Badge.tsx`): Status indicator badge supporting variants like success, warning, info, error, neutral.
- **ProgressIndicator** (`src/components/ui/ProgressIndicator.tsx`): Progress bar for the multi-step signup process.
- **Logo** (`src/components/ui/Logo.tsx`): Custom vector SVG brand identity for AquaVolt.
- **Sidebar** (`src/components/layout/Sidebar.tsx`): Collapsible navigation with icons and hover-to-expand mechanics.
- **LanguageSelector** (`src/components/navigation/LanguageSelector.tsx`): Custom ARIA-compliant dropdown for language switching.
- **StatusCards** (`src/pages/Dashboard/components/StatusCards.tsx`): Displays current status metrics.
- **RecommendationCard** (`src/pages/Dashboard/components/RecommendationCard.tsx`): Displays actionable "AquaVolt Advice".
